# Plataforma Académica Básica

Proyecto desarrollado para el taller de **Control de versiones con Git y GitHub**
de la asignatura Ingeniería de Software III — Universidad INCCA de Colombia.

## Descripción

Plataforma Académica Básica es una maqueta web sencilla que simula el portal de
un estudiante: muestra sus asignaturas, las notas registradas y los anuncios del
docente. El objetivo del proyecto no es construir una aplicación funcional
completa, sino servir de base para practicar el flujo de trabajo colaborativo con
Git y GitHub: creación de repositorio, uso de ramas, commits descriptivos, envío
de cambios al remoto, pull request, revisión entre compañeros y fusión con la
rama principal.

## Tecnologías

- HTML5
- CSS3
- JavaScript (vanilla)
- Git y GitHub para el control de versiones

## Flujo de trabajo utilizado

1. Creación del repositorio remoto en GitHub.
2. Clonación local con `git clone`.
3. Creación de la rama `feature/estructura-inicial`.
4. Commits descriptivos por cada cambio realizado.
5. Envío de la rama al remoto con `git push`.
6. Pull request hacia `main` y revisión entre compañeros.
7. Fusión (merge) de los cambios aprobados.
